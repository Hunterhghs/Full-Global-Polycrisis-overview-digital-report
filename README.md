# Full Global Polycrisis Overview — Digital Report

A professional-grade digital report on the full global polycrisis: the six core stress domains, the missing earth-system domains, and the secondary impacts — wildfires, feedback loops, and cascading failures.

Deployed via GitHub Pages.

## Pages

| Page | Contents |
|---|---|
| `index.html` — Overview | Six-node system map, the four transmission mechanisms, warming record, and the report's core claim |
| `earth-system.html` — Earth System | Biodiversity, ocean acidification/deoxygenation, land aridity, freshwater stress, cryosphere tipping points, pollution |
| `secondary-impacts.html` — Secondary Impacts | Wildfires, the five feedback loops, compound events, and insurance/fiscal cascades |
| `systemic-domains.html` — Systemic Domains | Energy access, antimicrobial resistance, sovereign debt, digital security, supply chains, demographics |
| `data-sources.html` — Data & Sources | Headline data tables and the full source register |

## Stack

- Vanilla HTML/CSS/JS — no build step, no npm
- Chart.js 4 (CDN) for interactive charts
- H Heuristics brand token system (`css/tokens.css`, `css/components.css`)
- Cormorant Garamond + Source Sans 3 + JetBrains Mono via Google Fonts
